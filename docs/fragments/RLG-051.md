### RLG-051 — A time-of-day setting in the pre-race menu
- **RULED 2026-08-28T17:50:07-04:00** — **Owner, 2026-08-28:** "Another setting I want added to the pre-race menu: time of day (dusk,
midnight, dawn, midday)."

**Most of this already exists, and that is the useful finding.** road.js:7380 runs a full day cycle
on a wall clock - `DAY_SECONDS = 240`, `dayClock`, and `phase()` returning 0 to 1 - with the four
points named in the code exactly as the owner named them:

| phase | the code's name | the owner's name |
|---|---|---|
| 0.00 | dusk | dusk |
| 0.25 | night | midnight |
| 0.50 | dawn | dawn |
| 0.75 | day | midday |

So this is not new rendering. `nightFall()`, `goldenBand()`, the sun and moon placement, the lit
signs, the verge dimming and the cruiser livery choice all already key off `phase()`. **The setting
is a starting value for `dayClock`, plus a control in the garage.** It should be a small unit, and
if it turns out not to be, that is a signal that something reads the phase in a way this note has
missed.

**It is a wall clock and not an odometer, deliberately** - the comment records that tying the cycle
to distance meant slowing down slowed time and flooring it sped time up, "a paradox you feel every
time you brake". Any implementation must not undo that.

**ONE THING IS UNDECIDED AND IT CHANGES THE BUILD. Put it to the owner.** Does choosing a time of day
set where the cycle STARTS, with the four minutes then running on as they do today - or does it PIN
the light, so "midnight" means the whole race is at night? The word "setting" fits either. They are
different features:

- **starting phase** is a one-line change at race start and keeps the cycle, which is what the
  engine was built around and what a 12-mile race currently shows off
- **pinned** means a race can be run entirely in the dark, which is a thing players ask for, but it
  makes `phase()` constant and nothing has ever run with it constant. The golden band, the sun
  placement and the headlight logic have only ever been exercised while moving

**Related but NOT the same thing:** [[RLG-044]] gives traffic muted palettes and racers saturated
ones. A pinned midnight would be the harshest test that colour still reads as a class signal when
there is very little light to read it by. Worth doing them in an order that lets the second check the
first.
