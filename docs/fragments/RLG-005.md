### RLG-005 — The machines are renamed: Quietus, and the REDLINE marque
- **RULED 2026-08-28T09:45:22-04:00** — - **Owner rulings, 2026-08-25.** The inherited names were generic and are replaced.

  | Was | Is | Why |
  |---|---|---|
  | Derelict | **Quietus** | supersedes the owner's parked project of that name |
  | Highway | **Redline Interstate** | the endless road |
  | Raceway | **Redline Motorsport** | the circuit |
  | Privateer | *(open)* | the word collides with Origin's *Wing Commander: Privateer*, 1993 |

- **REDLINE is a marque, and that is the honest structure rather than branding.** Highway and
  Raceway are not two games that look alike. They are **one engine** - `road.js`, 9,849 lines - with
  the same six cars in the same garage, separated only by a `CFG` seam. A shared parent with two
  disciplines describes what is actually there. The model the owner named is Forza: one marque,
  an open-road title and a circuit title.

- **Quietus supersedes a real project, and the supersession is coherent rather than a reuse of a
  liked word.** `Projects/Parked/Quietus` is a **menu-only salvage game**: you pilot a salvage ship
  to derelict wrecks and send a drone inside through a terminal interface. Derelict here is the same
  fiction given a body - a dead ship you are inside of, where nothing is alive and plenty still
  moves. **The owner's intent is that this project supersedes that one when it goes standalone.**

- **Two facts about the parked project that matter later, recorded now so they are not rediscovered.**
  1. **It is already Godot 4.7 / GDScript**, targeting iOS and Android from one codebase. That is
     exactly one of the two exit routes named for these machines ([[RLG-002]]). Whatever that project
     solved about shipping a Godot game to a phone is prior art for this one, not a dead end.
  2. **It holds the repository `EffigyMedia/quietus-dev`.** When Quietus goes standalone it either
     takes that repository over or takes a new one, and the environment already has a convention for
     the first - `Projects/Retired/Effigy_Audio_superseded_monorepo` is the precedent. **That is a
     decision for the moment it happens, not now**, and nothing in this project should assume it.

- **The rename is NOT performed in this unit.** It touches game ids, file paths, the catalogue, both
  cache lists, and the `localStorage` save keys - and **saves are keyed by id, so a rename orphans
  them**. There are no players yet, so it is free now and expensive later. It is held so that all
  four names land in **one** unit: one cache bump, one commit, one moment where saves are allowed to
  break. The fourth name is the only thing outstanding.
