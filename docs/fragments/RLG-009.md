### RLG-009 — Hardpoint gets a proper title: a drawn wordmark, the career read back, and an honest first button
- **RULED 2026-08-28T10:45:10-04:00** — - **What was there was a placeholder, not a front door**: a plain `<h1>`, four buttons, and a best
  time. Three things were wrong with it, and each is a separate fault rather than one taste
  disagreement.

- **1. It did not say who you are.** Hardpoint keeps a career - credits, a pirate standing, a hunter
  standing, an owned locker - and the title showed a best time only. There is now a three-column
  strip reading STANDING, CREDITS and BEST RUN straight back off the save. **It is drawn only when a
  career exists**, so a first launch is not a wall of zeroes.

- **2. Its first button lied.** `startRun()` opens the STATION - you always begin docked - so PLAY
  landing on a station screen was a small confusion the player had to resolve for themselves. The
  button says `BEGIN` on a fresh save and `CONTINUE` once there is something to continue, with a
  line under it naming where it goes.

- **3. QUIT hardcoded a path, and a dead one.** It went to `../../index.html#em`, naming a shelf
  that no longer exists. `Arcade.home()` exists precisely so one place decides where home is - it
  reads the cabinet's own meta tag - and every other machine already used it.

- **The wordmark is drawn, not typeset.** `Arcade.wordmark` is the painter every cabinet uses, so
  HARDPOINT is set in the arcade's own hand rather than in a web font, in warm brass over the hull
  grey the rest of the game is painted in. Verified by reading the canvas back for non-transparent
  pixels rather than by assuming it drew.

- **Proof, in both states.** First launch: primary reads `BEGIN`, no career strip, wordmark canvas
  has paint on it. With a career seeded: primary reads `CONTINUE`, the strip reads
  `PIRATE | 640 | 31.7s`. No page errors in either. `smoke-test` 6/6, which includes this cabinet's
  erase path walking in through the rebuilt menu.
