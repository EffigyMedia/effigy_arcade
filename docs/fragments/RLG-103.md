### RLG-103 — A missing selector aborted every Interstate run for as long as it existed
- **RULED 2026-08-31T09:13:46-04:00** — Queue item 6. The thread carried this as "drive-test's broken #score check", which is what it looked
like from the outside: one red line in an otherwise green run, reported for weeks as "18/19 passed".

IT WAS NOT ONE FAILING CHECK. IT WAS SIX CHECKS THAT NEVER RAN. `page.eval_on_selector('#score', ...)`
does not return a falsy value when the selector misses - it THROWS. The throw left the function, and
every Interstate assertion after that line went with it: speed against nine tenths of the car's top
end, the rev limiter, distance travelled, staying on the road, and damage. The Interstate is one of
the two games this engine serves, and its driving has not been measured for as long as this has been
broken. The harness said 18/19 and meant "I checked one game".

THAT IS THE FAULT WORTH RECORDING, NOT THE SELECTOR. A red line is honest: somebody reads it and
knows something is wrong. A red line that also silently truncates the run is a harness reporting a
denominator it did not earn - 19 checks, of which one game contributed five. The count looked almost
green, which is why it survived being on a queue for days as a low-priority tidy-up.

THE SELECTOR ITSELF: `#score` exists in Motorsport and does not exist in the Interstate, whose live
figures are `#clock`, `#dist` and `#place`. So Motorsport passed and the Interstate died on the same
line.

FIXED BY ASKING FOR THE EFFECT RATHER THAN ONE MACHINE'S IMPLEMENTATION OF IT. `#hud` is the container
both machines have, and its text changes when anything inside it does - which is exactly what the
check is named for. `hud_text()` reads it through `page.evaluate` and returns `None` rather than
throwing, so a machine with no HUD at all now FAILS a check instead of ending the run. This project's
own guidance says it in one line: test for the effect, not for your own implementation of it.

WHAT THE INTERSTATE ACTUALLY REPORTS, now that it is asked: peak 152mph against a 122 threshold, revs
at 100.0 per cent of the limiter and never past it, 192,332 units of road under the car, on the road
for 100 per cent of samples, worst damage 13 per cent. None of that had been read before. 27 of 27
now, against 18 of 19.

AND THE 13 PER CENT IS A NUMBER NOBODY HAS SEEN, so it is written down here rather than assumed
harmless. It is well under the wreck threshold and the run never respawned, but it is the first
recorded damage figure for an Interstate run and there is nothing to compare it with yet.

TWO BLEMISHES IN THE FIX ITSELF, both caught before the commit and both worth a line. The regex was
written with a `\s` escape in a non-raw Python string, which Python warns about and will stop
accepting - it is a raw string now. And the "the machine has a HUD to read" check printed the detail
"no #hud element on the page" WHILE PASSING, because this harness prints the detail whether or not
the check passed; a detail line has to read true in both directions, so it reports the length instead.
