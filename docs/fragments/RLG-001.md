### RLG-001 — Effigy Arcade forks from Tiny Arcade: four machines on one floor
- **RULED 2026-08-28T09:12:37-04:00** — - **What this is.** A new product, in a new repository, forked from Tiny Arcade at v0.9.11 and cut
  down to four machines: Derelict, Privateer, Highway and Raceway. Each one is meant to be built out
  into a full multi-scene game rather than filled in.

- **Why a repository and not a branch.** The owner asked which was right, and the deciding fact is
  that **GitHub Pages serves one branch**. Reshaping `main` would have taken the nineteen-game
  arcade offline; a branch would never have been served at all. Two repositories keep both playable
  at their own addresses, and the owner's stated goal - to leave Tiny Arcade as a playable record in
  time - is met without any further care. **The parent is never touched again.**

- **What carried over.** The shell (`arcade.js`), the synthesizer (`audio.js`), the 9,849-line
  driving engine that IS Highway and Raceway, the four machines, both Playwright harnesses,
  `harness.py`, the packer and its gates, the offline layer, and the fonts the four machines use.
  The git history came across whole rather than squashed.

- **What did not.** Fifteen machines. The three-shelf structure. Fourteen of the twenty-seven fonts,
  which belonged only to the machines that left - 324KB off the offline precache, measured before
  and after.

- **One floor.** `SHELVES` holds a single entry whose id is `all`, and `all` matches every cabinet.
  The launcher opens straight onto the rack; nothing lands on a picker. **The shelf mechanism is
  kept whole rather than torn out**, because a fifth machine is plausible and a real picker is one
  entry away. The back button went with the picker it returned to, and its listener is bound through
  the null-safe `on()` helper so putting the button back is one line. The loading panel now covers
  the floor rather than the picker; otherwise the rack painted underneath it and the attract screens
  ran behind it.

- **Everything branded was renamed before anything shipped** - the catalogue global
  (`window.EFFIGY_ARCADE`), the `localStorage` key prefix, the service-worker cache names, the zip.
  **A storage key or a cache name renamed after release strands whatever a player already has**, so
  this is the one moment it is free.

- **The version reset to 0.1.0, and the code did not get younger.** Tiny Arcade's 0.9.11 described a
  nearly finished arcade of nineteen small machines. This product is four machines that have barely
  started becoming what they are meant to be, so carrying the number over would have claimed the
  opposite. The maturity of the engine is recorded in the history, which came across whole.

- **Two defects were found while cutting, both latent in the parent.**
  1. The new "every `.md` is accounted for" gate tested a file named `*.md`. An unmatched glob stays
     literal in bash, and Tiny Arcade always had six documents at its root, so it could never fire
     there. Guarded with `nullglob`.
  2. The archive step assumed `zip` is on `PATH`. The build therefore passed all six gates and then
     died on its last line. It now falls back to PowerShell's `Compress-Archive`, and it asserts the
     archive exists rather than trusting the archiver's exit code.

- **Proof.** `./pack.sh` passes all six gates and produces a 764KB archive of 37 files. The harness
  results are recorded in this unit's commit.
