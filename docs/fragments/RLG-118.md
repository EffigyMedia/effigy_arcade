### RLG-118 — The grid is already at racing speed when the count reaches zero
- **RULED 2026-08-31T12:58:41-04:00** — Owner, 2026-08-31: "Can you find out what in the code is making race opponents zoom off on GO at what
I'm only assuming is their top speed?"

FOUND, AND THE ASSUMPTION IS VERY NEARLY EXACT. It is two lines that are individually reasonable and
wrong together.

At grid setup, every rival is given a speed:

    r.base = r.vmax * (0.99 - i*0.008 + rnd(-0.006, 0.006));
    r.spd  = r.base * 0.92;

So a rival is INITIALISED at about 0.92 x 0.99 of its own top speed - roughly 91 per cent - before the
race has started. The owner guessed "their top speed"; it is 91 per cent of it, and the difference is
not visible from the driving seat.

And the count-in never touches them. `step()` holds the player at rest and RETURNS:

    if(countIn > 0){
      ...
      spd = 0; nosOn = false;
      return;
    }

That return is what keeps the world still during the count, and it works by not running the rest of
the frame - which includes `stepRacers`. So the rivals are not held at zero; they are simply not
stepped, and they keep the 91 per cent they were handed. The instant the count reaches zero the return
stops firing, and eleven cars that were already at racing speed start moving at racing speed while the
player is at 0 in first gear.

NEITHER LINE IS A MISTAKE ON ITS OWN. Handing a rival a speed at setup is right for a race that begins
mid-flow, which is what a rolling start is, and the engine did that before there was a count-in.
Freezing the world by returning early is right, and it is what RLG-088 built. Put together they make a
standing start in which only the player is standing.

THE FIX IS THE STANDING START THE COUNT-IN ALREADY IMPLIES: the grid begins at rest and accelerates
from the line. `r.spd = 0` at setup, and `stepRacers` gets the cars up to `r.base` using the pull they
already have - `r.pull` is `accelOf(r.body)` and exists.

AND IT MEETS [[RLG-110]] EXACTLY. The owner has separately asked for the car to sit in neutral through
the count so it can be revved and launched on GO. A launch the player wins or loses is meaningless
against a field that was never standing, so these two are one piece of work: the whole grid launches,
or none of it does.

WATCH THE SKILL SPREAD WHEN IT IS BUILT. `r.base` already strings the field out by starting position -
`0.99 - i*0.008` - and that spread exists to stop the grid arriving as a block. From a standing start
the spread should come from the LAUNCH as well, which is what makes a start interesting; but the
existing base spread must not simply be added to a launch spread, or the back of the grid will never
see the front again.

AND CHECK WHAT ELSE READS THE INITIAL SPEED. `stepRacers` is skipped for the whole count, so anything
that reasoned about rivals during it has been reasoning about stationary cars at 91 per cent - the
cruiser's target search among them, which looks for anything above 0.44 of top speed.
