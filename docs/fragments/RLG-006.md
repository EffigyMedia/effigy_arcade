### RLG-006 — The rename, performed as one unit: Quietus, Hardpoint, Redline Interstate, Redline Motorsport
- **RULED 2026-08-28T09:59:29-04:00** — - **All four at once, deliberately.** The names were held until every one was settled ([[RLG-005]])
  because a rename touches game ids, file paths, the catalogue, both cache lists **and the
  `localStorage` save keys** - `Arcade.save` keys on `SKEY + id`, so a changed id orphans every save
  under the old one. One unit means one cache bump and one moment where saves are allowed to break.
  There are no players yet, which is the only reason that moment is free.

  | Was | Now | id | file |
  |---|---|---|---|
  | Derelict | **Quietus** | `quietus` | `games/em/quietus.html` |
  | Privateer | **Hardpoint** | `hardpoint` | `games/em/hardpoint.html` |
  | Highway | **Redline Interstate** | `interstate` | `games/sw/interstate.html` |
  | Raceway | **Redline Motorsport** | `motorsport` | `games/sw/motorsport.html` |

- **Why Hardpoint, and why not the obvious ones.** The owner reframed the game mid-discussion: it is
  not a privateering story, it is a **small-scope FPS SIMcade RPG** in which **the player chooses to
  be a pirate or a bounty hunter**, with procedurally generated work besides. That choice rules out
  every name that picks a side - MARQUE, PRIZE, QUARRY, WARRANT, BOUNTY all commit the player before
  they have played. What survives is a name about the machinery both roles use, and `hardpoint`
  spans all three genres at once: a weapons mount in flight sims, an objective in shooters, and
  exactly the thing an armoury and a refit fill.

- **The ids are the discipline, not the marque.** `interstate` and `motorsport` rather than
  `redline-interstate`. Inside one arcade the discipline is unambiguous, it keeps
  `pack.sh --standalone interstate` readable, and the marque lives in the display name and on the
  title card where a player sees it.

- **Prose was renamed by meaning, not by pattern.** Only the capitalized forms are the games' proper
  names. `motorsport.html` says "a circuit is **not a highway**" about its own track - lowercase, the
  English word for a road, still true, left alone. Inside `road.js` the marque was dropped again
  after substitution: that file serves these two games and nothing else, so "Interstate" and
  "Motorsport" identify them without repeating "Redline" twenty times.

- **`docs/reference/PRIVATEER.md` keeps its name.** It is a frozen record written before the rename,
  and the in-code citations to it - `PRIVATEER.md 5b`, `6`, `7` - stay correct. It was protected
  through every substitution rather than being caught by them.

- **`arcade-home` lost its shelf hash.** Each cabinet pointed at `../../index.html#em` or `#sw`,
  which addressed a shelf picker that no longer exists and which the landing code now ignores.

- **THE CACHE GENERATION HAD TO BUMP AGAIN, and this one is worse than the icon.** Every cabinet
  **filename** changed, and every one of them is in the generated cache list. A returning visitor
  whose worker still holds the old list asks the server for four files that are no longer there.
  Bumped v25 to v26. `assets.js` was seeded by hand again, which is [[RLG-004]]'s deadlock.

- **What is knowingly left alone.** The `cat` folders `em` and `sw` are inherited from Tiny Arcade's
  shelves and now mean nothing - the floor shows every cabinet regardless of `cat`. Renaming them
  would churn both cache lists and every path a second time for no behavior. Recorded in the brief
  rather than done.

- **Proof.** `pack.sh` all gates, 38 files, 688KB. `smoke-test` 5/5 - launcher, quietus, interstate,
  motorsport, hardpoint. `drive-test` 21/21 across INTERSTATE and MOTORSPORT.
