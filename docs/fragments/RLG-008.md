### RLG-008 — Every machine can erase its own save from its own options
- **RULED 2026-08-28T10:41:20-04:00** — - **Every machine now offers ERASE SAVE in its own options screen**, behind a two-press confirm:
  the first press arms and the label becomes `SURE?`, the second erases and reloads.

- **No dialog, deliberately.** Each of these menus is already a veil over the game. A confirm dialog
  would be a second veil over the first on a phone, which is how a player loses their place. The
  arm-then-confirm pattern is the launcher's own, so the arcade behaves one way.

- **A reload, not a redraw, and this is the part that would have been a bug.** Everything each
  machine read at boot - unlocked cars, options, the deepest deck, the locker choice - is in
  variables by the time the button is pressed. Clearing the store without reloading leaves the page
  holding exactly what it just deleted, and **the next save writes it all back**. The erase would
  have appeared to work and then silently undone itself.

- **The label reads the store rather than assuming.** With nothing saved it says `NO SAVED DATA` and
  does nothing. A button that offers to erase and does not is worse than one that says so.

- **The shell clears; the game draws the button.** `Arcade.save.clear` knows every key a machine owns
  ([[RLG-007]]). The control itself is written three times, once per idiom - `.go ghost` in the
  driving engine, `.vbtn ghost` in Quietus, a bare button in Hardpoint - because **the shell does not
  know what a cabinet's buttons look like and must not**. One edit in `road.js` serves both driving
  machines, which is the seam working as intended.

- **A defect found while reading, inherited and now obvious.** `road.js` hardcoded
  `<div class="eyebrow">HIGHWAY</div>` on the Options and Debug screens. That file serves BOTH
  driving games, so Raceway had been showing Highway's name above its own options since before this
  project existed. It reads `GAME_TITLE` now.

- **PROVEN in the harness, not asserted.** `smoke-test.py` drives the real path for every machine:
  seed a save so the label cannot read `NO SAVED DATA`, walk in through OPTIONS, assert `ERASE SAVE`
  is on screen, assert one press ARMS rather than erasing, then confirm and look at the store on the
  far side of the reload. **A static check cannot see a button**, and this is a must-flow.

- **Proof.** `pack.sh` all gates; `smoke-test` 6/6 with the new per-machine erase assertions;
  `drive-test` 21/21 after the `road.js` edit.
