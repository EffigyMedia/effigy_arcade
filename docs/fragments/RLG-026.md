### RLG-026 — Interstate: a stale tournament rewards system is still triggering
- **RULED 2026-08-28T13:51:41-04:00** — - **Owner report:** there was an older rewards system for tournaments that is now stale but still
  fires.

- **Before deleting anything**, find what still calls it and what it writes. A rewards system that
  touches the save is one that can be granting or clearing unlocks behind the current one, and two
  systems writing the same keys is a different bug from one dead system firing harmlessly.
