### RLG-091 — Night becomes day by degrees, not in one frame
- **RULED 2026-08-30T20:42:36-04:00** — Owner, 2026-08-30: the transition from night to day, and from day to night, is a gigantic snap. It should lerp.

THE DAY IS 240 SECONDS AND THE LIGHT IS READ FROM A PHASE, so something in that chain is reading a BRANCH rather than a blend - a test for whether it is night, used where a proportion belongs. clockLamps already returns a fraction and ramps across dawn, which is why the street lamps and the headlights fade correctly; whatever snaps is reading the hour some other way. Find the branch before writing any easing, because easing a value that is already smooth would leave the snap exactly where it is.

THE GROUND TONE IS THE FIRST PLACE TO LOOK. groundTone takes a `dark` argument that is a BOOLEAN, and a boolean cannot be halfway. The biome work has a note about the same function taking both an hour and an amount, so the shape for a blended answer may already be there.

AND IT IS TWO TRANSITIONS, NOT ONE. Dusk and dawn are separate crossings and only one of them may be broken; the owner named both, so check both rather than fixing the one that is easier to reach. A capture across the phase - the same instrument the beam and biome work used - will say where the step is to the frame.
