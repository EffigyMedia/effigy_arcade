**Constraints in force**
- Tiny Arcade is a SEPARATE repository and is never touched from here. It is parked, complete and still playable at effigymedia.github.io/tiny_arcade
- never edit this product through the GitHub web UI - an upload replaces a whole file, so there is no merge and no conflict. Six shipped fixes were reverted that way in the parent, behind a green build
- keep pack.sh --standalone working. It emits one self-contained HTML file per machine, and that is the exit route when a game is split into its own binary wrapper
- commits are authored as the project owner - no AI identity, no co-author trailer. One unit, one commit, committed immediately
- MOBILE ONLY - touch is the input. Keyboard, mouse and gamepad are out of scope (owner ruling 2026-08-25, RLG-002). The inherited Arcade.menu and A.pad layers stay for now but are not load-bearing; do not extend them

**Unfinished**
- the games are to be RENAMED - the owner said so at the fork. Derelict, Privateer, Highway and Raceway are working titles, and Privateer in particular shares its name with a 1993 Origin game
- each machine is to become a full multi-scene game. Nothing of that is built yet; what forked over is the arcade-cabinet form of each
- sync.sh is inherited and obsolete - it clones the remote to a temporary folder and copies files over the top, from when the working folder was not a repository. This folder is the repository. Delete it or rewrite it
- no audit has been run against this repository. The parent's audit findings were remediated before the fork, so the four machines carry those fixes, but the launcher is new work and has never been audited
- each machine leaves by one of two routes - a binary wrapper around the web build, or a conversion to Godot. Under the Godot route this codebase is the playable design document rather than the shipping artifact, so web-only plumbing is not worth investing in (RLG-002)
- drive-test.py steers with a keyboard. If desktop input is ever removed from the driving games, the harness must learn to drive by touch FIRST - it is the only automated proof the engine still drives
- Hardpoint is a small-scope FPS SIMcade RPG where the player chooses pirate or bounty hunter, with procedural work besides (owner, 2026-08-25). docs/reference/PRIVATEER.md is its design document and keeps that filename - it is a frozen record written before the rename
