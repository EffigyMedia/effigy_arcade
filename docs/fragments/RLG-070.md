### RLG-070 — The formula class: three cars, and a ladder of classes to earn them
- **RULED 2026-08-29T09:42:37-04:00** — Owner, 2026-08-29, in several parts across one conversation. Motorsport needs a grid of open-wheelers,
and a grid of one car repeated is not a race.

THE CLASS. There is one formula car no longer; there are three. VECTOR launches, COMET runs, APEX
sits between them - the same trade the supercars make, moved up a class. Every one of them is at
least twenty per cent above the BEST supercar in every stat, not above the average: the reference
points are MATADOR's 1.24 pull, STALLION's 1.03 top end, CREST's 1.42 grip and 1.32 brakes, and
STALLION's 710hp.

    VECTOR   248mph   pull 1.86   grip 2.05   brake 1.95   980hp   690kg
    APEX     260      1.70        2.00        1.90        1020    720
    COMET    276      1.56        1.92        1.82        1080    760

They share ONE design. The owner ruled that unique bodywork was not needed - cars from a single
formula are near enough identical from behind, and a name, a badge and a stat block is what separates
them. An earlier pass had built three aerodynamic packages, and it was taken back out. Each wears its
own marque: VECTOR two struck blue chevrons, APEX the gold bolt the single formula car always had,
COMET an orange head with a tail behind it.

THE CLASS IS A CLASS, and that is what makes it work. `classOf` returned 'super' for a formula car,
so the one open-wheeler in the game raced against road cars. It returns 'formula' now, and everything
downstream follows the class rather than naming the cars: the grid, the ladder, the yoke instead of a
rim, no stripes, no indicators, no wipers. Nothing has to name these three again.

TWO PAINTERS, TWO MEANINGS OF `kind`. This cost two wrong drawings in a row. In `paintFront`, `kind`
is the BODY KEY. In `paintCar`, `kind` is `B.rear` - the MARQUE. Testing the body key in the tail
painter drew a supercar's tail on every open-wheeler; testing the marque there would have drawn one on
the two cars that wear their own badge. The tail is entered by `isFormula(o.bodyKey)` and the badge is
looked up per car.

THE LADDER. A fresh install holds the SPORTS class and nothing else. Each gold opens the next class
up, and a class IS its tournament, because a tournament is run in the class of the car taken to it -
so owning the cars is having the ladder open, and there is no second flag to keep in step.

    start          the sports class - ROADSTER, TUNER, MUSCLE
    sports gold    the SUPER class
    super gold     the FORMULA class, all three
    formula gold   the iridescent paints

The supercars used to be the starting cars, which made the sports class a consolation prize for a
tournament run in cars that were already better than it. The paint moved to the top because it is the
only prize that is not a car, so it can sit above the last class without making anything obsolete.

The silver and bronze prizes were the TUNER and the MUSCLE car, and both are in the starting class
now. The merges stay, because a save may already hold those flags and nothing should rewrite an old
save, but they gate nothing. WHAT SILVER AND BRONZE SHOULD PAY INSTEAD IS AN OPEN QUESTION for the
owner rather than something to invent here.

NOBODY LOSES A CAR THEY ALREADY HAD. The supercars were free until this ruling, so any save showing a
career - a prize won, a car chosen outside the sports class - is granted the super class on load. A
save with none of that starts at the bottom like everyone else. A save holding the retired FORMULA
body key becomes an APEX; without that it would fail the BODY test in silence and drop the player
back into a MATADOR.

THREE DEBUG SWITCHES, one per locked group: all racers, police, all traffic. There were two, and the
patrol car rode on the racers' switch - so testing a pursuit opened every class on the ladder with it.

AND NO FORMULA CAR EVER APPEARS IN TRAFFIC. The owner ruled that a supercar may show up in traffic
very rarely in a muted colour (RLG-054, not built); a formula car never does, at any rate, under any
condition. The traffic kinds are an explicit list of road-car rigs, so this holds today by
construction - the rule is written down so the rare-supercar work does not quietly widen it.

The harness had to learn the class too. `lamp-test` excepted the formula car from the indicator check
BY NAME; there were three open-wheelers by the end of the same day and two of them are not called
FORMULA. It reads the class now. A class cannot be widened by a rename.
- **RULED 2026-08-29T11:29:42-04:00** — Owner, 2026-08-29, from the device: "it seems like I am starting with supercars in my garage too."

The ladder was working - a fresh profile offers TUNER, MUSCLE and ROADSTER and nothing else, and that
was checked. What was wrong was the MIGRATION beside it, which grants the super class to a save that
shows a career so that a returning player does not open the garage and find their car gone.

It counted the SAVED CAR as evidence of that career. The old default body was a MATADOR, so every
save ever written holds a supercar key whether the player ever won anything or not - and the
migration handed the whole class to all of them.

Only a PRIZE counts now: the formula, iridescent, cruiser, supercruiser, traffic, tuner and muscle
flags. Those are written when a tournament is won and by nothing else, so a save holding one earned
it under the old rules and keeps what it earned. A save that only ever had a car chosen in it starts
at the bottom of the ladder like everybody else.

The general shape is worth keeping in mind for any migration written later: a DEFAULT is not
evidence. Anything every save holds cannot distinguish one save from another, and a test against it
is a test that always passes.
