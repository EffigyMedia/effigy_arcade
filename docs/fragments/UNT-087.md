### UNT-087 - The mirror stops throwing trees at you

- Routing class: `feature` -> **claude-sonnet-5**, effort **medium**. Bias 1. Implementation to a spec that already answers the design questions. ([[RLG-092]])
- Opened for: [[RLG-073]]
- Opened by `unit.py`. **The identity exists before the first edit** ([[RLG-097]]), so the snapshot has somewhere to go.
- **CLOSED 2026-08-30T23:51:29-04:00** - The mirror walks an absolute world grid instead of fixed distances behind the car. It was not receding at all: rproj takes distance as pos minus world position, and the loop wrote the world position as pos minus a fixed distance, so every slice sat at a constant distance back for ever. The glass was a ladder of rungs that never moved and the placement hash swapped which tree stood on each rung as the car drove. Measured, the frame-to-frame size change of a mirror object was exactly 0.00 per cent against 0.55 out of the windscreen; it is 0.52 now. No tolerance on SPEED would have caught that, because the mirror was not slow, it was stationary - the discriminating assertion is that it moves at all. Same fault hillClip had, third time in this engine. TWO WRONG DIAGNOSES CAME FIRST: the forward view was measured instead of the mirror and found exact, which was correct about the wrong view; and the near cut was tightened from a fifth of the pane to a tenth on a theory that close objects set the rate - reverted, because it was only in the tree when the real cause was found. The fade at that cut is kept: a cut is not a fade, and an object used to appear abruptly at its largest allowed size. fps unchanged - FOREST 48.4 to 51.6 against a 46.4 to 53.2 baseline, the same overlapping band.
