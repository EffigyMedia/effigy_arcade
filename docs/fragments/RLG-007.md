### RLG-007 — Erasing a machine now erases all of it, and a harness check proves it
- **RULED 2026-08-28T10:35:09-04:00** — - **`Arcade.save.clear(id)` removed one key and reported success.** A machine that had been erased
  still remembered its options (`<id>-opts`), anything it had stored under its own name (Quietus
  keeps a tally and an intro flag), and every intro the shell's cinema had already shown it. **The
  launcher's own ERASE was worse**: it matched `effigyarcade.save` only, under a note that promised
  it cleared runs in progress.

- **The fix is a namespace rule, written into the shell where it is enforced.** Everything the arcade
  stores lives under `effigyarcade.`, and everything ONE machine stores lives under exactly two
  shapes: `effigyarcade.save.v1.<id>` with any `-suffix`, and `effigyarcade.<id>.<anything>` for what
  the machine writes itself. **A machine that stores outside those shapes is invisible to the
  eraser**, which is the failure this replaces rather than a new risk. `save` and `cinema` are
  reserved and cannot be ids.

- **The cinema is a prune, not a delete.** Every machine's "already seen" flags live in ONE blob at
  `effigyarcade.cinema.v1`, so clearing one machine has to reach inside it and take only its own
  entries.

- **`-` and `.` in the key tests are load-bearing.** A bare prefix test would let a machine called
  `inter` claim `interstate`'s keys. The tests are exact-match, `<id>-`, and `<id>.`.

- **Added:** `save.has(id)`, so a menu can tell whether there is anything to erase rather than
  offering a button that does nothing; `save.clearAll()`, which the launcher now calls; and `clear`
  returns how many keys went, so a caller can say something true.

- **PROVEN, not asserted.** `smoke-test.py` gained a `saves()` check that seeds all four shapes plus
  a neighbour whose id shares a prefix, erases one machine, and looks afterwards. **It was then run
  against the OLD implementation to confirm it is not vacuous**, and it failed exactly as it should:

        FAIL  saves  - erasing a machine leaves none of its keys
                       (effigyarcade.inter.tally.v1, effigyarcade.save.v1.inter-opts);
                       and forgets the intros it had shown
                       ({'inter.intro': 1, 'interstate.intro': 1})

  The check also asserts the prefix neighbour SURVIVES, which is the half a careless fix breaks.

- **What this unit does not do.** The per-machine erase control in each title menu is the next unit;
  this one gives it something correct to call. Hardpoint's title menu is the unit after that.
